# Baseline Domain Model — Current Develop Tree

Scope: this describes the geometric and construction-history domain as it exists in the current source tree. It does not rely on prior audit artifacts.

## Executive summary

The canonical in-memory model is centered on `World`, but ownership is split: `World` owns projection planes, hinge lines, 3D planes/elements, caches, `ProcessTree`, and `DependencyService`, while each `ProjectionPlane` owns its 2D points, lines, circles, guides, segments, and half-hinge lines. The domain distinguishes **definitions/rules** (domain objects storing IDs and construction relationships) from **realizations** (computed numeric geometry). Commands are generic containers over reversible operations; tools and factories build operation sequences. The process tree stores construction history as subprocesses, action groups, and action nodes, while geometric dependencies are tracked separately by `DependencyService`.

## Root world and ownership

`World` is documented and implemented as the root container for geometric entities and the complete construction state (`frontend/src/domain/world/World.ts:2`, `frontend/src/domain/world/World.ts:4`, `frontend/src/domain/world/World.ts:113`). It explicitly states the current ownership hierarchy as `World → ProjectionPlane → Element2D`: 2D elements are owned by projection planes, not stored directly by `World` (`frontend/src/domain/world/World.ts:14`, `frontend/src/domain/world/World.ts:15`, `frontend/src/domain/world/World.ts:16`, `frontend/src/domain/world/World.ts:74`). `World` still provides semantic and ID-based access to planes and high-level domain objects (`frontend/src/domain/world/World.ts:57`, `frontend/src/domain/world/World.ts:59`, `frontend/src/domain/world/World.ts:60`, `frontend/src/domain/world/World.ts:754`, `frontend/src/domain/world/World.ts:765`, `frontend/src/domain/world/World.ts:778`).

`World` owns maps for hinge lines, 3D planes, projection planes, and user-created 3D elements (`frontend/src/domain/world/World.ts:115`, `frontend/src/domain/world/World.ts:116`, `frontend/src/domain/world/World.ts:117`, `frontend/src/domain/world/World.ts:119`). It exposes process-tree and dependency-service accessors (`frontend/src/domain/world/World.ts:914`, `frontend/src/domain/world/World.ts:921`) and add/get/remove methods for 3D points, lines, segments, and planes that register or unregister dependency nodes (`frontend/src/domain/world/World.ts:1114`, `frontend/src/domain/world/World.ts:1116`, `frontend/src/domain/world/World.ts:1147`, `frontend/src/domain/world/World.ts:1149`, `frontend/src/domain/world/World.ts:1180`, `frontend/src/domain/world/World.ts:1182`, `frontend/src/domain/world/World.ts:1213`, `frontend/src/domain/world/World.ts:1215`).

## Projection planes P_H, P_V, and auxiliary planes

## Points

## Hinge lines and broken hinge/paired-plane behavior
