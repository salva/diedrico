# Baseline Architecture Map — Current Develop Tree

Scope: current `develop` source tree only. This map intentionally does not use prior audit cycles or earlier proposals.

## Executive summary

The application is nominally layered as Vue entry/app shell → UI components/composables/stores/tools → command/operation sequences → domain world/process-tree/calculation model → rendering/persistence/integration services. In practice, several boundaries are porous: the domain root imports command and service layers, the canvas component directly constructs tools and operations, persistence reconstructs every operation class with a large switch, and multiple stores/components duplicate or bypass the canonical `World` ownership model. The largest god-modules are `SvgCanvas.vue`, `ProjectionPlane.ts`, `World.ts`, `ThreeView.vue`, `App.vue`, `PaperService.ts`, and `ProjectService.ts` by line count (`frontend/src/components/workspace/SvgCanvas.vue:181`, `frontend/src/domain/world/ProjectionPlane.ts:176`, `frontend/src/domain/world/World.ts:113`, `frontend/src/components/panels/ThreeView.vue:64`, `frontend/src/App.vue:106`, `frontend/src/services/PaperService.ts:108`, `frontend/src/services/ProjectService.ts:98`).
