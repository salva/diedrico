# What is Diedrico?

Diedrico is an educational drawing application for learning dihedral projection. It focuses on the construction process: users create explicit geometric objects, inspect dependencies, and see how 2D projections relate to a 3D interpretation.

It is not a general CAD package. The current application is a frontend-only browser app with a 2D workspace, a read-only 3D view, undo/redo, process-tree visibility, local/browser persistence, and optional Google Drive save/load.
